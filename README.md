# Weir Shingle: Monorepo · Vercel and Render

A monorepo with three apps on two hosts: `avens-ep4` and `bugle-zes` on **Vercel**, `cudweed-ebx` on
**Render** (a static site). Preview links are **public** on both. Static Vite + TypeScript, no
framework. The page reads a live list from the shared Supabase test project.
